# openhauss

**The Intelligent Real Estate Platform**

openhauss is a modern real estate tech brand built with [Next.js](https://nextjs.org), TypeScript, and Tailwind CSS. It connects buyers, sellers, and renters with AI-powered insights, transparent pricing, and a seamless end-to-end digital experience.

## Brand Identity

| Token | Value | Usage |
|---|---|---|
| Primary | `#1a3c5e` | Navy blue — trust, authority |
| Accent | `#e8825a` | Coral orange — warmth, energy |
| Background | `#f5f7fa` | Light grey — clean, spacious |

## Features

- 🏠 **Property Search** — filter by location, type, and price with auto-complete suggestions
- 🤖 **AI Price Intelligence** — real-time hyper-local property valuations
- ✅ **Verified Listings** — fraud-checked and manually reviewed
- 🎥 **Virtual 3D Tours** — immersive walkthroughs before in-person visits
- 📍 **Neighborhood Insights** — schools, commute, walkability, and more
- 📄 **Digital Closing** — e-sign, escrow tracking, and document management
- 💰 **Mortgage Calculator** — monthly payment estimates and lender connections

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- [Next.js 15](https://nextjs.org) (App Router)
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS v4](https://tailwindcss.com)
- [Geist Font](https://vercel.com/font)
